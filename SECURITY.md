# Security and engineering hazards

This engineering prototype has no qualified physical power assembly. A software
pass is not a hardware safety finding. Historical output, exposure and
compliance claims under archive/ are withdrawn.

Report reproducible software faults through this repository's security advisory
channel when available. Include affected revision, inputs, reproduction steps
and observed behavior. Do not publish private credentials or personal data.
No response-time or hardware-remediation SLA is represented by this document.

Independent voltage/current/thermal cutoffs, correctly rated fuses and a
watchdog are necessary physical design work. The delivered AVR image builds
in monitor mode. It has not been flashed or field tested here.
