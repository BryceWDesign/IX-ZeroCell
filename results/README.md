# Result provenance

`release_verification.json` is the current coordinated run receipt. `verification.json` reports the current Python/native suite and energy campaigns. `stack1000/` contains the new numerical and behavioral circuit results; all label their origin and retain hardware_validated=false. `reference_build/` retains the smaller ZC-D10 circuit proof, rerun for this package.

The older donor-audit JSON and donor test logs report earlier donor investigations, not tests of new power hardware. Earlier summary logs not referenced by the current release receipt are historical and do not override the current receipt. The original 2025 claims live under archive and remain withdrawn.

No result is a physical ZeroCell measurement. The header-only measurement CSV is an acquisition format, not evidence.
